# Minimum Probability Flow Learning

This directory contains an implementation of Minimum Probability Flow (MPF) learning based on the paper: https://arxiv.org/pdf/0906.4779v4

The implementation applies MPF to the Ising model and follows the reference code available at: https://github.com/Sohl-Dickstein/Minimum-Probability-Flow-Learning/tree/master/MPF_ising
